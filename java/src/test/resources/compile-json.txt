⚠️ Why it still fails

The COBOL runtime doesn’t automatically look in the executable’s directory for modules unless it’s explicitly told to — even if both files are side by side.

When you run ./out-1/MainJson, your working directory is probably not out-1/, but rather its parent (e.g., project root).

So at runtime, it’s checking . (the current directory) for JsonParse-String, not out-1/.

✅ Two simple fixes
Option 1: cd into out-1/ before running
cd out-1
./MainJson


Now the working directory is out-1, so CALL "JsonParse-String" will find the module in . (the current folder).

Option 2: Run with a runtime path
COB_LIBRARY_PATH=out-1 ./out-1/MainJson


This explicitly tells the COBOL runtime to look in out-1/ for modules.
